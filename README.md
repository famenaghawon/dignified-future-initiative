# Dignified Future Initiative (DFI) Website

Official website for the Dignified Future Initiative (DFI) Ltd/Gte (RC 9861744).

## About
DFI is a youth-led organization committed to empowering young people through leadership development, policy advocacy, and community-based initiatives in Nigeria.

## Tech Stack
- **Framework:** [Astro](https://astro.build/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Language:** TypeScript
- **Hosting:** [Cloudflare Pages](https://pages.cloudflare.com/)

## Local Development

1. Clone the repository:
   
   git clone https://github.com/famenaghawon/dignified-future-initiative.git
   cd dignified-future-initiative


1. Install dependencies:
   
   npm install
   
2. Start the development server:
   
   npm run dev
  
3. Open http://localhost:4321 in your browser.

Deployment

This site is automatically deployed to Cloudflare Pages via GitHub. Any push to the main branch triggers a new build.
